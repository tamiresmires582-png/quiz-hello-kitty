# Quiz Front-End

Quiz interativo com 27 perguntas sobre front-end, desenvolvido com HTML, CSS e JavaScript.

## Sobre o Projeto

Este projeto foi desenvolvido para praticar conceitos de front-end, incluindo:

- HTML semântico
- CSS (Flexbox, responsividade)
- JavaScript (DOM, eventos, arrays, funções)
- TypeScript (interfaces, types, union types)

## Funcionalidades

- 27 perguntas sobre front-end
- Explicações detalhadas quando o usuário erra
- Pontuação em tempo real
- Tela inicial e botão "Jogar de Novo"
- Design responsivo

## Tecnologias

- HTML5
- CSS3
- JavaScript
